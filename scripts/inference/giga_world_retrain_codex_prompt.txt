任务二：正确实现delta action统计量

目标表示：

- 前5个关节：delta_action = target_action - current_state
- gripper：保持absolute target_action
- mask：[true, true, true, true, true, false]

必须基于转换后的混合action表示重新计算统计量：

hybrid_action[..., 0:5] = action[..., 0:5] - state[..., 0:5]
hybrid_action[..., 5] = action[..., 5]

然后使用hybrid_action自己的统计量进行归一化。

优先比较：

A. 当前错误baseline：delta action + absolute stats
B. 修复方案：delta/hybrid action + MEAN_STD
C. delta/hybrid action + robust quantile normalization
D. absolute action baseline，不使用delta

不要预先假定哪一个最好。先计算分布并运行小规模训练，用物理角度误差选择方案。
